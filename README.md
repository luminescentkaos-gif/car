
# 无人车编程开发项目
本项目围绕无人车底层运动控制开展开发，采用**STM32主控芯片**，分别在Keil5裸机开发、Ubuntu虚拟机编译环境下完成程序开发、固件编译、文件传输与HiBurn烧录部署，实现虚拟机与Windows主机的文件互通，完成无人车控制固件全流程开发。

## 项目简介
无人车底层控制基于STM32单片机，分为两套开发方案：
1. Windows端Keil5直接进行裸机开发，编写电机控制、传感器采集、运动逻辑代码；
2. Ubuntu虚拟机搭建交叉编译环境，完成工程代码编译，生成`.bin`固件；
通过VMware共享文件夹实现Ubuntu编译产物向Windows传输，最终使用HiBurn工具将固件烧录至STM32主控板，完成无人车底层程序部署。项目同时完成虚拟机环境配置、文件传输方案对比、Linux环境踩坑调试等工作。

## 开发环境
### 硬件
- 主控芯片：STM32系列单片机
- 无人车底盘、电机驱动模块、传感器模块
### 软件环境
- Windows端：Keil uVision5、HiBurn烧录工具、VMware Workstation
- 虚拟机端：Ubuntu 22.04、GCC交叉编译器、open-vm-tools、Git
- 版本控制：GitHub

## 功能模块
1. Keil5裸机开发：完成STM32底层GPIO、定时器、串口、电机驱动代码编写，实现无人车基础运动控制
2. 虚拟机环境搭建：安装VMware Tools，实现剪贴板互通、鼠标无缝切换、分辨率自适应
3. 文件互通配置：VMware单向共享文件夹，Ubuntu编译固件输出至Windows
4. 固件编译与烧录：Ubuntu交叉编译生成bin固件，Windows通过HiBurn完成STM32烧录
5. 备选传输方案：SFTP网络传输，适配大型工程、多文件固件同步
